# Privacy Policy

**Effective Date:** 2025-08-09
**Last Updated:** 2025-08-09

## 1. Introduction

Freequency ("we," "our," or "us") is a **free, non-commercial** music practice social media platform that respects your privacy and is committed to protecting your personal information. This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our platform ("Service").

By using our Service, you consent to the data practices described in this Privacy Policy.

## 2. Information We Collect

### 2.1 Information You Provide Directly

**Account Information:**

- Name (display name, given name, family name)
- Email address
- Profile picture (from Google account)
- Bio and profile description (optional)
- Musical instruments you play

**Practice Content:**

- Practice session descriptions and notes
- Photos, videos, and audio recordings of practice sessions
- Practice tasks and goals
- Duration and timing of practice sessions
- Tags and categorization of practice content

**Social Interactions:**

- Comments on other users' posts
- "Gas Ups" (likes/encouragement) given and received
- Following relationships with other users
- Messages and communications (if applicable)

### 2.2 Information Collected Automatically

**Usage Data:**

- Pages visited and features used
- Time spent on different sections of the app
- Click patterns and navigation behavior
- Device information (browser type, operating system)
- IP address and general location information

**Technical Data:**

- Log files and error reports
- Performance metrics and crash data
- Session replay data (for debugging purposes)
- Cookies and similar tracking technologies

**Analytics Data:**

- User engagement metrics
- Feature adoption rates
- Practice session statistics
- Goal completion rates

### 2.3 Information from Third Parties

**Google OAuth:**

- Profile information (name, email, profile picture)
- Google account ID for authentication
- We do not access other Google services or data

**Error Monitoring (Sentry):**

- Error logs and debugging information
- User behavior leading to errors
- Technical performance data

## 5. Data Security

### 5.1 Security Measures

We implement industry-standard security measures to protect your information:

- **Encryption:** Data is encrypted in transit and at rest
- **Authentication:** Secure OAuth authentication through Google
- **Access Controls:** Limited access to personal data on a need-to-know basis
- **Monitoring:** Continuous monitoring for security threats
- **Regular Updates:** Regular security updates and patches

### 5.2 Data Storage

- **Location:** Data is stored in secure cloud infrastructure (AWS)
- **Retention:** We retain data only as long as necessary for service provision
- **Backups:** Secure backups are maintained for data recovery purposes

### 5.3 Limitations

While we implement strong security measures, no system is completely secure. We cannot guarantee absolute security of your information.
